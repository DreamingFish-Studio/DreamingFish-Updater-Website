同步策略与本地管理

完整解释默认同步、强制同步、文件移除、玩家本地豁免、模组启停与规则优先顺序。

两种同步模式#

默认同步

只维护明确托管的内容

发布清单中的文件缺失或损坏时恢复；不在清单中的玩家额外文件默认保留。玩家可以对普通托管内容设置本地豁免。

  • 适合大多数整合包项目
  • 保留玩家兼容配置与自选模组
  • 文件管理边界清晰、温和
强制同步

指定范围必须与发布一致

可以按一级目录递归强制，也可以只强制一个具体文件。玩家本地豁免和模组停用不能绕过这些规则。

  • 适合核心模组和关键配置
  • 强制目录中的额外文件会移入归档
  • 设置变化需要重新扫描并发布

默认同步的具体行为#

  • 托管文件不存在：重新下载并恢复。
  • 托管文件内容损坏或被修改：恢复为当前发布内容，除非玩家已设置本地豁免。
  • 玩家额外添加的非托管文件：保留并提示，不主动删除。
  • 玩家自选模组：保留，可在玩家端中启用或停用。
  • 服主从发布中移除文件：按“删除玩家文件”或“放弃管理并保留”执行。

强制同步的两种粒度#

强制同步一级目录#

例如把 mods 设为强制同步后，该目录会递归收敛到发布清单：缺失文件恢复，内容变化被覆盖，额外文件移入玩家归档。其他未设置强制的目录仍按默认同步处理。

强制同步单个文件#

只要求一个关键文件保持一致时，可以单独指定，例如 config/server-required.toml。这不会清理同目录其他文件，也不会把整个 config 变成强制目录。

!
首次部署建议先不要启用强制同步

先用默认同步跑通完整流程并确认玩家端行为，再为真正关键的目录或文件增加强制规则。强制范围过大容易误伤玩家的兼容内容。

玩家本地管理#

本地操作效果限制
豁免单个文件普通托管文件不再自动覆盖、恢复或删除不能作用于强制文件或强制目录内文件
豁免整个目录该目录下普通托管内容停止本地管理不能绕过服主强制目录
停用模组JAR 移到本地停用目录，之后可恢复必要依赖可能导致崩溃；强制模组不可停用
恢复默认管理清除对应本地选择，重新接受发布管理通常在下次启动检查中重新收敛

这些规则只保存在玩家电脑，不会上传给管理端。重新启用目录管理时，玩家端会整理该目录下冗余的单文件规则，避免互相冲突。

放弃管理与玩家豁免不是一回事#

  • 放弃管理：由服主在发布时决定，对所有玩家生效；文件从远程托管范围退出。
  • 玩家本地豁免：由单个玩家在自己的电脑决定，只影响该玩家，并且不能覆盖强制规则。

规则优先顺序#

  1. 强制同步目录或强制同步文件优先，玩家本地设置不能绕过。
  2. 对普通托管内容，玩家本地豁免优先于安装、覆盖和删除。
  3. 没有本地豁免时，按当前发布的目标状态更新或移除。
  4. 不属于发布清单且不在强制目录中的内容，视为非托管文件并默认保留。

典型配置示例#

开放型生存服

保持全项目默认同步，只把一个连接相关配置设为强制文件。玩家可以保留小地图、光影和个人配置。

严格竞技整合包

把 mods 设为强制目录，其他目录保持默认同步。额外模组会归档，但截图、日志和未受管配置不会被全盘清理。
