版本与更新日志

查看当前组件版本与近期主要改进。玩家端、管理端和 Bootstrap Agent 分别发布，版本号不要求保持一致。

玩家端 0.1.19管理端 0.1.16Bootstrap Agent 0.1.2整理日期 2026-07-31

当前组件版本#

组件版本主要职责
玩家端0.1.19启动前检查、差异更新、界面、日志和本地管理
管理端0.1.16项目、源文件、扫描发布、实例与文件服务
Bootstrap Agent0.1.2在 Minecraft 加载前启动玩家端并等待许可

玩家端 0.1.19#

  • 更新服务器不可达时，明确区分本地托管内容变更与更新器状态损坏。
  • 对可明确归类的本地文件修改提供二次确认后的继续启动选项。
  • 签名、项目绑定、危险路径、事务和程序完整性问题仍然不能绕过。

玩家端 0.1.18#

  • 完善玩家自选模组页面，支持搜索、启用和停用。
  • 优化模组风险提示和窄窗口下的文本布局。
  • 深化内置新闻与“守望梦屿”导览内容。

管理端 0.1.16#

  • 增强 Web 管理页面的引导、字号和操作可读性。
  • 完善项目、源文件、强制同步、扫描发布、历史回滚和玩家实例页面。
  • 统一远程管理的 SSH 隧道提示并修复弹窗交互问题。

为什么三个版本号不同#

三个组件生命周期不同。玩家端界面变化不要求管理端同步升级；管理端发布能力变化也不一定需要更新 Agent。独立版本能让升级范围更小，也避免把模组内容版本与更新器程序版本混淆。
