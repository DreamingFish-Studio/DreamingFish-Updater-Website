下载与首次配置

让我们跟着这篇教程一步步来：下载解压管理端，完成第一次运行时的引导配置，让管理端先跑起来。

一、先认识两个组成部分#

开始部署之前，先记住整个系统由两个部分构成：管理端和 玩家端。管理端可以运行在运行 Minecraft 的服务器上，也可以运行在其他服务器上；玩家端运行在玩家电脑上，由玩家端本体和 Agent（启动引导器）组成。让我们先认识这两个部分。

服主使用

管理端

安装在服务器上，负责管理内容、发布版本、制作玩家实例，并启动玩家下载服务。

玩家使用

玩家端

随整合包发给玩家的桌面程序，由玩家端本体和 Agent（启动引导器）组成。本体负责在游戏启动前检查和更新文件；Agent 挂在启动器里，负责拉起玩家端、等待启动许可，并参与玩家端自更新与失败回退。

一次启动的协作过程：

服主发布在管理端维护标准目录、扫描并发布新版本。
服主完成启动器接入按 PCL 或 HMCL 的实际规则配置 Agent，并确认版本隔离生效。
玩家启动游戏启动器加载 Agent，Agent 再拉起玩家端。
返回启动许可玩家端完成检查后放行，Minecraft 正常加载。

二、准备发行包与三个位置#

管理端和玩家端发行包都自带运行环境，不需要额外安装 Java。建议先准备以下三个固定位置：

Windows 目录示例
D:\管理端       管理端程序与自动生成的数据
D:\被管理的文件      服主希望更新器管理的内容
D:\待发布的完整游戏版本      准备发给玩家的完整 Minecraft 实例
  • D:\管理端 应长期保留，升级管理端时继续使用其中的 data 和设置文件。
  • D:\被管理的文件 不要求是完整游戏目录。只管理模组时可以只有 mods；只管理配置时也可以只有需要的 config。
  • D:\待发布的完整游戏版本 是最终交给玩家的完整实例，它由启动器、游戏文件和 DreamingFish 组件共同组成。

三、下载解压管理端#

解压到固定目录

Windows 将管理端压缩包解压到 D:\管理端；Linux 将管理端压缩包解压到长期使用的目录，例如 /opt/dfs-admin。两边都一样：不要每次升级都新建一套空目录。

运行管理端

Windows 双击 DreamingFishAdmin.exe 或从 PowerShell 启动；Linux 解压后在发行包根目录运行 ./dfs-admin，建议用 tmux 挂起（如 tmux new -s dfs ./dfs-admin），断开 SSH 后管理端仍会继续运行。

[1/3] 管理端数据保存位置
管理端会把项目设置、发布记录和签名密钥自动保存在下面这个文件夹：
  /opt/dfs-admin/data
这个 data 文件夹位于管理端根目录中，非常重要，请勿删除！
i
data 里面会放什么？为什么重要

项目设置、发布记录、签名密钥和全部内容对象都存在 data 里，相当于管理端的“全部家当”。升级或迁移管理端时，把旧版本的 data 连同 management-settings.json 等设置文件一起搬到新版本根目录，项目和发布历史就会原样恢复；备份时也请优先备份 data，不要只复制一个空目录。

玩家更新器会通过这项服务下载模组和配置文件。

这里填的不是公网地址

这一步配置的是服务器上的监听地址和端口：0.0.0.0 表示允许其他电脑连接，8080 是默认内网端口。玩家真正访问的公网地址（例如 http://你的公网IP:端口）要等创建项目时才填写；如果 8080 被其他程序占用，就换一个空闲端口。

第 3 步 · Web 管理页面
[3/3] Web 管理页面
这个页面只给管理员使用，不要提供给玩家。
  默认端口是 18080，通常直接按回车。
  默认只监听 127.0.0.1；需要公网访问时，先通过本机或 SSH 隧道注册账户，
  再在服务设置或 Web 页面显式改为 0.0.0.0，并务必配置 HTTPS 反向代理。
Web 管理端口（一般直接按回车） [18080]：
i
Web 管理页面只给管理员用

它默认只监听 127.0.0.1，只有管理端本机能打开。远程服务器上想用浏览器管理时，先通过 SSH 隧道访问，不要把 18080 直接暴露到公网。不用 Web 也没关系，终端菜单同样能完成所有操作。

是否现在启动 Web 管理界面并创建第一个项目？ [Y/n]：Y
✓
很好，你已经完成了首次设置！
  1. 推荐按 Y 进入网页配置模式：管理端会自动启动 Web 管理界面，你在浏览器里填写项目信息，每个字段都带用途和示例。
  2. 无图形界面的 Linux 需要 SSH 隧道：服务器上打不开浏览器，先在你自己的电脑上建立 SSH 隧道再访问管理页面，不要把 18080 直接暴露到公网。
  3. 如果你无法使用 Web：也可以按 N 进入命令行模式，使用便捷的终端交互创建项目。
