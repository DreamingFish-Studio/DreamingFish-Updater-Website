常见问题

集中回答版本选择、VPS 管理、玩家自选内容、维护方式、界面切换与玩家端程序删除等常见疑问。

我该用桌面版还是终端版？#

看管理端放在什么系统上。Windows 电脑或 Windows Server，推荐直接用桌面版，解压就能运行；Linux 服务器或 VPS 用终端版，平时在浏览器里打开它的网页管理界面，和桌面版的界面一模一样；连网页也不方便用的时候（比如只能连 SSH、不想建隧道），就用终端版自带的交互式命令行。几种方式能做的事基本一样，区别见下面「做的事情一样吗」。

管理端在 VPS 上，如何打开 Web 页面？#

先在 VPS 上的终端版启动 Web 管理界面（交互式命令行主菜单 [10]），再从自己的电脑建立 SSH 隧道：

SSH 隧道
ssh -N -L 18080:127.0.0.1:18080 用户名@您的服务器地址

保持终端运行，并在自己电脑打开 http://127.0.0.1:18080/。本机的 18080 被占用了，就把命令里第一个 18080 换成别的空闲端口，浏览器地址也跟着换。自己的电脑是 Windows 的话，也可以直接用桌面版的“SSH 连接”，填好 SSH 配置名称和管理端口，桌面版会自己建好转发，做法见「远程管理与 AI agent」。

玩家自己添加的模组会被删除吗？#

普通同步下会保留。只有两种情况会被移走（都会先备份，玩家能在“备份与恢复”里看到）：一是服主把整个 mods 文件夹设成了强制同步，玩家额外放进去的模组会被移出；二是玩家自己放进去的正好是服主明确要求移除的那个模组，或者被标记为问题版本的那个文件。只强制单个文件的话，不会顺带清理同目录的其他模组。

玩家已经豁免或停用了，服主删除后还会处理吗？#

会。服主选“移除玩家副本”并发布后，就算玩家在本机豁免了、停用了，或者改了文件名，这个文件也会先备份再移出。豁免只是说“平时这个文件我自己管”，不代表有问题的文件可以绕过服主明确的移除要求。想让玩家留着，服主应该选“停止维护，留给玩家”。

首次提供和普通同步，怎么区分？#

普通同步会一直跟着服主更新，玩家缺了会补上；首次提供只给一份，玩家已经有了就不动，之后服主再改也不覆盖，玩家删了也不会反复补回来。想给玩家一份默认的画质、按键配置，之后让玩家自己改，就选首次提供。

玩家跳过了几个版本，或者拿旧整合包第一次进服，会不会漏删文件？#

不会。每次发布都会写清楚最新的客户端应该是什么样子，包括哪些文件必须移除，玩家端直接对齐到最新，不靠“有没有经过某个中间版本”来判断。只要包里的项目绑定和签名基线是对的，拿着很旧的完整包进服，也会按最新版本处理。当然，玩家离线时还不知道你新发的版本，要等下次联网启动检查。

标准整合包目录必须是一份完整游戏吗？#

不需要。它只需要包含服主希望由更新器管理的目录和文件，比如 mods、config、resourcepacks。游戏本体、存档、日志和启动器通常不应放入标准目录，管理端的 data 更不能放进去。

能直接上传 ZIP 吗？#

“发放”→“玩家端程序”可以直接上传玩家端发行 ZIP，管理端会检查程序版本和平台。但“文件”页的导入文件是一个个文件或文件夹导进来的，不会把整合包 ZIP 自动解压成模组目录。两个地方的用途不一样，别把整合包 ZIP 当成更新器发行包传上去。

新版界面和旧版界面有什么区别？该用哪个？#

功能是一样的，读写的也是同一份项目，只是布局不同：新版和桌面版的界面一模一样，旧版是原来的左侧菜单布局。网页默认打开新版，顶部的“旧版界面”和旧版右上角的“新版界面”可以来回切，浏览器会记住你的选择。也可以直接访问地址：/workbench/ 是新版，/legacy/ 是旧版。

桌面版、网页和交互式命令行做的事情一样吗？#

项目、维护规则、检查、签名和发布用的是同一套服务，结果完全一样。桌面版和网页管理界面多了导入清单、实时预览、发行 ZIP 检查这些可视化操作；交互式命令行更适合服务器上已经整理好的文件，维护方式这类高级设置用参数式命令完成。加密备份和恢复目前只在交互式命令行里提供。

Web 管理页面必须一直开着吗？#

不必须。Web 页面适合管理操作，关掉浏览器也不会停掉管理服务。不过正在上传文件的时候别关整个标签页，收起导入清单没关系。准备长期只运行玩家下载服务时，可以停止 Web 并在交互主菜单中单独选择 [9] 启动 HTTP 文件服务。桌面版关掉窗口会收进托盘，下载服务继续运行。

玩家端发布后可以删除吗？#

可以从历史里移除，不影响整合包发布。不过删之前确认一下，还有可用的玩家端程序版本给玩家更新：当前的玩家端、整合包要求的最低玩家端版本和以前发出去的部署包都可能用到它，别为了清理列表把唯一能用的版本删掉。

为什么更新器是 0.2.1，整合包却填 1.0.0？#

0.2.1 是更新器程序自己的版本，管理端和玩家端都用这个号；整合包的版本号是服主自己填的，只用来描述你自己的内容发布；Bootstrap Agent 是 0.1.2。这三个版本各管各的，平时更新模组不需要跟着改程序版本。
