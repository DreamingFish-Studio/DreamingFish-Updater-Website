常见问题

集中回答 VPS 管理、玩家自选内容、Web 常驻与玩家端程序删除等常见疑问。

管理端在 VPS 上，如何打开 Web 页面？#

先在 VPS 的交互终端启动 Web 管理界面，再从自己的电脑建立 SSH 隧道：

SSH 隧道
ssh -N -L 18080:127.0.0.1:18080 用户名@您的服务器地址

保持终端运行，并在自己电脑打开 http://127.0.0.1:18080/。

玩家自己添加的模组会被删除吗？#

默认同步下会保留并提示。只有当 mods 被服主设为强制同步目录时，额外模组才会被移出实例，并进入玩家归档。

标准整合包目录必须是一份完整游戏吗？#

不需要。它只需要包含服主希望由更新器管理的目录和文件。游戏本体、存档、日志和启动器通常不应放入标准目录。

Web 管理页面必须一直开着吗？#

不必须。Web 页面适合管理操作。准备长期只运行玩家下载服务时，可以停止 Web 并在交互主菜单中单独选择 [9] 启动 HTTP 文件服务。

玩家端发布后可以删除吗？#

可以删除。已发布的玩家端程序版本可以从历史中移除，不影响整合包发布。
