日常维护

恭喜你完成了配置！日常维护其实很轻松：改文件、扫描、发布；需要时回滚、备份、升级，一件件来就好。

日常更新客户端流程#

日常更新其实就三件事：给客户端加东西、从客户端删东西，或者放弃管理某个文件。不管哪一件，改完「整合包文件目录」后重新扫描并发布，玩家下次启动时就会自动跟上。

为客户端增加文件#

想给玩家加新模组、新配置？跟着这几步走：

  1. 把文件放进「整合包文件目录」里对应的位置——如果有新模组就放进 mods，如果有新配置就放进 config。
  2. 重新扫描：Web「管理文件」页点「↻ 扫描整合包目录」，或终端选 [4] 扫描并发布。
  3. 在变更预览里确认新文件都出现了，填好本次显示版本和更新记录，发布。

发布后，玩家下次启动时更新器就会下载这些新文件、放进对应位置——不用玩家手动做任何事。

为客户端删除文件#

想从玩家客户端移除某个文件或模组？把文件从「整合包文件目录」里删掉，重新扫描。如果扫描发现源目录里有文件被移除了，管理端会问你这个文件在玩家端怎么处理：

  1. 从玩家端删除：玩家下次启动时，这个文件会被清理掉。
  2. 只放弃管理，保留玩家本地文件：服务器不再管理这个文件，玩家电脑上已有的副本原样保留，可以继续使用。
!
什么时候选放弃管理？

当你只是“不想再更新这个文件”、而不是“玩家必须删掉它”的时候。比如某个模组不再维护了，但玩家留着玩没影响——选放弃管理，玩家就能保留它，服务器也不再推送更新。注意两点：放弃管理是对所有玩家生效的，和玩家在自己电脑上单独豁免文件不是一回事；另外强制同步目录或强制同步文件里的内容只能删除，不能放弃管理。

i
发布是不可变的

内容有误就修正目录再发新版本，不要修改旧版本；也可以在网页端快捷回滚，把某个历史版本作为新版本重新发布。玩家端会自动发现并升级到最新版本，低于最低玩家端程序版本的玩家端会先更新程序再更新整合包。

更新玩家端程序#

玩家端程序是另一条独立的发布线，和整合包内容互不影响：平时更新模组、改配置，只重新发布整合包就好。而玩家端程序是可以自更新的——想给玩家推送新闻、更换更新器背景，或者调整其它个性化内容时，发布一个新版本的玩家端程序就好；玩家端下次启动会自动检查并安装，不用再把客户端重新发给玩家。

真正需要重新分发玩家端的情况只有一种：Bootstrap Agent 更新了。Agent 挂在启动器里、由启动器在游戏加载前先拉起，没法像玩家端那样自更新；而 Agent 一般不会更新，除非有重大 Bug——所以绝大多数情况下，玩家端程序都能自己追上最新版。

发布新玩家端程序和第一次完全一样：Web「玩家端程序」页选好平台、填最低 Bootstrap Agent 版本、选玩家端发行包解压后的根目录，点「发布玩家端」；终端选 [6]。玩家端程序更新拥有独立的签名清单，安装失败时会回退到上一个已验证版本，不会和整合包内容混在一起。发布整合包时如果填的最低玩家端程序版本高于玩家当前版本，玩家端会先更新程序、再更新整合包。完整的首次发布流程见「创建第一个项目」第 5 步。

创建回滚发布

点击「回滚」会弹出创建回滚发布的窗口：目标版本已经选好，填一个新的显示版本和更新记录，确认后玩家端就会收到一个“回到旧版本”的新发布。

终端选 [5] 查看发布历史（新版本在前），会列出序号、显示版本、发布 ID、时间和更新记录：

查看发布历史 · [5]
发布历史（新版本在前）：
  #2  1.0.1  r000002-20260802-200000-ab12cd34  2026-08-02T20:00:00Z
       修复一个模组崩溃问题
  #1  1.0.0  r000001-20260802-161030-ab12cd34  2026-08-02T16:10:30Z
       首次发布：接入模组与基础配置。

回滚的方式是：把某个历史发布作为新的目标状态，再发布一次——旧版本记录保留，玩家端会收到一个“回到旧版本”的新发布。终端命令：

回滚命令
dfs-admin project rollback 梦屿 r000001-20260802-161030-ab12cd34 --version 1.0.1 --changelog "回滚到 1.0.0" --yes

备份与恢复#

如果你特别看重安全性，可以给管理端做加密备份——它包含项目数据、发布记录和签名私钥，跨机器迁移或保护重要环境时用得上（终端专属，Web 不提供）。日常维护不做备份也没有关系。创建备份：

创建加密备份
dfs-admin backup create --output D:\备份\dreamingfish-20260802.dfb

密码从环境变量 DFS_BACKUP_PASSWORD 读取；未设置时会在终端中交互式输入并确认。恢复备份：

恢复加密备份
dfs-admin backup restore D:\备份\dreamingfish-20260802.dfb --force
!
不要只复制数据库文件或只导出私钥

备份要整个做、整个恢复。--force 会替换现有的管理数据目录，恢复前请确认没有重要新数据。

升级管理端#

  1. 下载新版管理端并解压。
  2. 把旧版根目录中的 data 文件夹、management-settings.json 和 management-web-auth.json（如果注册过 Web 账户）移动或复制到新版根目录。
  3. 启动新版管理端，程序会自动读取原有数据。

多项目维护#

一个管理端可以维护多个整合包项目。终端操作前会先列出项目让你选择，直接回车使用带 * 的默认项目；每个项目拥有独立的显示信息、公共地址、发布历史和签名身份，不同项目的玩家实例不要混用绑定文件（详见「创建第一个项目」）。
