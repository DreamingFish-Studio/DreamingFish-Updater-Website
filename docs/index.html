DreamingFish Updater/概览

玩家轻松更新，服主优雅管理。

梦鱼更新器是为广大 Minecraft 模组服设计的管理工具。开模组服的腐竹们应该都知道：模组出了 Bug，或者服务器崩服需要删改内容时，处理起来有多痛苦。一方面，你要清楚地告诉玩家该如何处理有问题的模组；另一方面，如果服务器有自制模组需要频繁更新，每次都让玩家手动修改，实在让人头疼。你可能还想给自己的服务器设计一个酷炫的启动客户端，在里面展示新闻、公告以及更多内容……因此，我们制作了梦鱼更新器。它是一个更新器，也可以成为你的服务器专属客户端。

梦鱼更新器是一个安全可靠、自主可控、易于部署的 Minecraft 客户端管理工具：服主在 Windows 上可以直接用桌面版，在 Linux 服务器上用终端版的网页或交互式命令行管理项目与发布，玩家端在启动前自动更新，玩家自己的模组和文件也始终保有清楚的控制权。

?
玩家是来玩服务器的，还是来玩资源管理器的？

把手动拖模组、反复对版本和担心更新失败的麻烦，交给梦鱼更新器。

服主

用桌面版或终端版管理内容与发布

管理端分为桌面版和终端版。管理端放在 Windows 电脑或 Windows Server 上，推荐直接运行桌面版（免安装），当然也能用终端版；Linux 服务器只有终端版，平时打开它的网页管理界面，和桌面版的界面一模一样；网页也不方便用的时候，还可以用交互式命令行。不管用哪种，读写的都是同一份项目数据，整理文件、选择维护方式、发布版本和制作玩家实例都能做。

玩家

启动前自动更新，同时保留控制权

玩家继续使用 PCL、HMCL 等现有启动器；服主需要先按对应启动器完成 Java Agent 接入，梦鱼更新器只在游戏启动前处理更新。

从服主发布，到玩家进入游戏#

整理文件添加、删除或更新模组、配置和资源，决定服务器要管理什么。
选择维护方式普通同步尊重玩家本地选择；强制同步守住关键内容；首次提供只给玩家一份初始配置。
自动更新只下载真正变化的内容，完成签名、哈希和安装检查。
安全启动更新失败自动恢复；成功后继续进入 Minecraft。

爱咋删，爱咋加，启动就完了。#

服主怎么删、怎么加，玩家端都能追到最新目标状态。普通同步下，玩家自己添加的模组和文件不会被误删；玩家还可以手动决定哪些本地内容继续交给更新器管理。

  • 服务器内容与玩家自选内容分开识别，互不打架。
  • 玩家可以按文件或目录管理本地内容，保留对客户端的控制权。
  • 读取 Forge/NeoForge 的 modId，识别 Fabric 模组 ID；模组升级或改名后仍能尽量保留选择。
  • 被替换或清理掉的本地文件都会先进入“备份与恢复”，玩家随时可以放回来。
  • 玩家端更新器可以独立自更新，与整合包更新渠道分开。

服主有三种维护方式#

管理端不把所有玩家电脑粗暴地全盘覆盖，而是让服主按内容的重要程度，给每个文件或文件夹选一种维护方式。不确定的时候，保持默认的普通同步就好。

DEFAULT · 普通同步

尊重玩家本地选择

适合大多数内容。服务器发布的内容会保持最新；玩家额外添加的模组和文件保留不动，玩家可以通过玩家端在本机停用模组，或者把普通文件改成自己管理。

  • 不主动删除玩家额外内容
  • 玩家可以自己管理文件和模组
  • 玩家改过的文件，换回前会先备份
FORCED · 强制同步

关键内容保持一致

适合核心模组、反作弊和必须一致的配置。开启后，玩家端会强制保持与服务器一致，玩家不能停用，也不能改成自己管理；整个文件夹设为强制同步时，玩家自己放进去的文件会先安全备份，再移出游戏。

  • 可按文件夹或单个文件开启
  • 关键内容始终跟随服务器版本
  • 移出的内容都能在备份里找回
FIRST · 首次提供

给份初始配置，之后不再管理

适合模组会自行修改、画质这类初始配置。玩家没有这个文件时提供一次；之后服主再改模板，也不会覆盖玩家自己的设置，玩家删掉了也不会反复补回来。

  • 玩家已有就保留
  • 缺少时只提供一次
  • 玩家可以主动恢复默认

从整合包里删掉某个文件时，管理端也提供了两种方式：是把玩家电脑上的副本也移除，还是停止维护、留给玩家自己用。这部分在「日常维护」里会细讲。

安全更新，不留下半套状态#

更新会保证完整性与安全性。梦鱼更新器先确认发布可信，再逐项校验，最后以事务方式安装；任何一步失败，都不会把未验证的状态交给玩家启动。

可信发布

管理端用 Ed25519 签名发布清单，玩家先确认项目身份与目标版本。

逐项校验

文件通过 SHA-256 与大小校验，损坏或不匹配的内容不会进入安装。

事务安装

先备份、再暂存、最后原子替换；中断时恢复原状态，不留下半套更新。

快捷回退

发现问题可一键回退到稳定发布，历史发布保持不被改写。

支持主流启动器#

启动器

PCL、HMCL 可以继续用，接入方式不同

梦鱼更新器不接管账号、游戏安装或实例选择。PCL 优先使用专属 {verpath} 参数；版本 JSON 的 arguments.jvm 可同时兼容 PCL 和 HMCL，分发前应检查实际启动命令。

模组加载器

Forge、NeoForge、Fabric 都能识别

通过模组元数据识别组件，帮助玩家保留自己的选择；服务器内容和玩家自选内容各自管理，避免更新时互相影响。
