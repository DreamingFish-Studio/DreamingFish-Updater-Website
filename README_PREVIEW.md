# DreamingFish Updater 官网 · 首页重新设计

首页改为深色沉浸式设计，使用产品真实截图与梦屿等主题原画，动效全部由原生 CSS / JS 实现，没有外部依赖，离线打开也能完整显示。

- 直接双击 `OPEN-WEBSITE.cmd` 或打开 `index.html` 即可预览。
- 文档页（`docs/`）按 0.2.0 更新，保留原教程界面演示、目录图和终端示例；模式说明采用官网风格卡片。宣传片保留新版画面并换成原创配乐。首页主要新增 `assets/home.css`、`assets/home.js`、`assets/img/`、`assets/fonts/subset/`。
- 系统开启“减少动态效果”或在手机上浏览时，会自动关闭置顶滚动场景，改为静态排版。

## 修改文档

- 双击 `EDIT-DOCS.cmd`（需要 Python 3），浏览器会打开本地编辑服务里的文档。点右下角“编辑本页”就能直接改正文，`Ctrl+S` 保存，内容会写回 `docs/` 下对应的 HTML 文件。
- 编辑栏可以把段落改成标题或小标题，也能加粗、加代码样式和链接；“目录名”是标题在右侧“本页内容”里显示的名字，留空就跟着标题走。界面演示和终端示例默认锁住，勾选“演示也能改”后才能改里面的字。
- 每次保存前，旧版本会备份到 `tools/edit-docs/backups/`，每页保留最近 30 份。
- 也可以直接用编辑器改 `docs/*.html`：正文在 `<!-- 正文开始 -->` 和 `<!-- 正文结束 -->` 之间。改了标题后运行 `python tools/edit-docs/server.py --toc`，重新生成右侧目录。
- 编辑脚本只由本地编辑服务临时插进页面，直接打开文件或部署出去的官网都不会带上它。

## 维护

- 修改首页文案后运行 `python tools/subset-fonts.py`，重新生成只含首页字符的字体子集（每个字重约 90 KB）。
- 需要更新截图时，替换 `promo-video-v3/assets/` 中的源图后运行 `python tools/make-images.py`。
